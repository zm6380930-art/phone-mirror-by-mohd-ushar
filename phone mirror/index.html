Controls (click the phone screen)

  • Left click = tap · click & drag = swipe · hold = long-press
  • Mouse wheel = scroll
  • Right click = Back · Middle click = Home
  • Type on your keyboard to type on the phone (Enter, Backspace, arrows work)
  • Esc = Back · F11 = fullscreen phone
Setup guide — which options to use

On your PC (once)

  • Install Node.js 18+ and Google's Android platform-tools (adb), and add adb to your PATH.
  • Use Chrome or Edge (needs WebCodecs).
  • Run node server.js, then open http://localhost:8080.

On your phone (Android)

  • Settings → About phone → tap Build number 7 times.
  • Settings → Developer options → turn USB debugging ON.
  • Xiaomi / Redmi / POCO: also turn on USB debugging (Security settings). Oppo / Realme / OnePlus: turn on Disable permission monitoring if you see it. Without this, you can see the screen but taps do nothing.
  • Optional: Stay awake ON so the screen doesn't lock while charging.
  • Plug in with a data-capable USB-C cable (a charge-only cable won't work). Set USB mode to File transfer.
  • Tap Allow on the “Allow USB debugging?” popup (tick “Always allow”).

Best settings

  • Default: Quality 1280 px · 8 Mbps.
  • Laggy / choppy? 960 px · 4 Mbps, and use a USB 3 port.
  • Want sharper? 1920 px · 16 Mbps.

Troubleshooting

  • No phone detected: try another cable/port, re-plug, make sure USB debugging is on.
  • “unauthorized”: unlock the phone and accept the popup.
  • Black screen in some apps: banking/DRM apps block screen capture on purpose.
  • Rotated the phone: press “Restart stream”.
  • Typing: only plain English letters/numbers/symbols are supported.
  • iPhone isn't supported by this method (Android only).
